# Evidencias de pruebas

Crear una subcarpeta por caso, por ejemplo `INV-01`, y guardar allí las capturas que demuestren el resultado.

Para cambios de stock, registrar el saldo anterior, la operación, el saldo posterior y el movimiento del historial. Para errores, capturar también el mensaje mostrado.

No guardar contraseñas, cookies, tokens de sesión ni datos personales reales. Las evidencias deben indicar fecha, responsable, navegador o dispositivo y versión del proyecto.

No hay evidencias de pruebas manuales todavía: los casos permanecen pendientes hasta ejecutarlos.
